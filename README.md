# Phrase — локальний тренажер англійської

Український інтерфейс, American English. HTML, CSS і vanilla JavaScript, без фреймворків, API та платних сервісів. Іконки — локальний набір Lucide SVG.

## Запуск

Відкрийте `index.html` у браузері. Для стабільного збереження прогресу запустіть команду з папки проєкту й надалі використовуйте ту саму локальну адресу:

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

Відкрийте http://localhost:8765. Сервер слухає лише цей комп’ютер. Зупинка сервера у терміналі — Ctrl+C. Повторний запуск на зайнятому порту не потрібен.

## Можливості

- В основному потоці — 141 вправа з готовими варіантами, зокрема 118 контрастів; 15 навчальних тем.
- Контрасти, життєві ситуації, змішана практика, швидкі контрасти з часом відповіді.
- Тільки вибір однієї відповіді: контрасти, пропуски з варіантами, контекст і пошук помилки. Письмові відповіді та складання речень тимчасово вимкнено в усіх режимах, включно з повторенням і закладками.
- Заняття: 5 слабких шаблонів, 5 контрастів, 5 життєвих вправ, 5 помилок. Якщо історії ще немає, недоступні групи замінюються контрастами.
- Повторення фактичних помилок: за днем, темою, шаблоном. Ручні закладки мають окрему сторінку.
- Підказки не додають балів. Пропуск не рахується помилкою.
- Статистика, шпаргалка, темна тема, клавіші 1–4 та Enter.
- Експорт / імпорт прогресу через сторінку статистики.

## Дані та логіка

`exercises.js` — самодостатній банк даних; одна ситуація може мати контраст, активний переклад та складання речення. Це різні формати закріплення одного шаблону, а не 315 різних граматичних правил.

Повний банк із 315 вправ збережено. Спільний фільтр `pool()` допускає до занять лише вправи з вибором відповіді; «Життєві ситуації» використовують контекстні запитання та контрасти. Ідентифікатори вправ, старі відповіді, статистика й закладки залишаються незмінними. Закладки письмових вправ приховано до повернення відповідного формату.

`engine.js` — localStorage, перевірка, статистика, вибір питань і повторення. `app.js` — маршрути та інтерфейс. `styles.css` — адаптивне оформлення.

Інтервали: 45 секунд після помилки; 10 хвилин, 1, 3, 7, 14 і 30 днів після послідовних правильних відповідей. Прострочені та складні шаблони отримують більшу вагу. Останні п’ять питань виключаються, якщо розмір добірки це дозволяє. За відсутності прострочених вправ доступна практика наперед. Засвоєння: три правильні відповіді поспіль за шаблоном.

Вільний переклад перевіряється за підготовленими відповідями та альтернативами, з нормалізацією регістру, пунктуації й поширених скорочень. Це не довільна перевірка англійської через ШІ: інший правильний переклад може потребувати додавання до `alternatives`.

Прогрес прив’язаний до браузера та адреси (схема, хост, порт). Перед зміною адреси або очищенням браузера експортуйте копію. Закриття вкладки завершує поточне заняття, але вже записані відповіді залишаються. Синхронізації між пристроями немає.

## Перевірка

```powershell
node tests.cjs
```

Перевіряються контракти всіх вправ, мінімальні обсяги тем, правильні та неправильні відповіді, збереження, фільтри повторення, серії, засвоєння, інтервали, закладки й відновлення після пошкодженого JSON.

Публічний тренажер: https://ihoryar-maker.github.io/phrase-english-trainer/

## Іконки

[Lucide](https://lucide.dev/) — `lucide-static` 1.55.0, ліцензія ISC. У `vendor/lucide/` збережено 24 офіційні SVG, ліцензію та походження з контрольним хешем npm-архіву. Геометрія іконок не змінена; додано CSS-клас і атрибути доступності. Іконки декоративні, усі дії мають текстові підписи.

Набір завантажується з цього ж сайту, без CDN і мережевих запитів до сторонніх сервісів; працює також при відкритті `index.html` локально.
